# Niblet

**Niblet** is a tiny AI palette for your Mac.

The goal is to make it easy to select text or capture something on your screen, press a shortcut, and run quick AI actions like summarizing, explaining, rewriting, or extracting TODOs.

Niblet is currently in early development.

## Planned Core Loop

```txt
Select text or screenshot → press shortcut → choose a Nibble → view response
```

## Tech

Niblet is being built as a native macOS app using Swift, SwiftUI, and AppKit.

## Status

Early experimental project.
